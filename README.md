# 🎓 GECA Student Academic Tools

A web-based academic utility project containing SGPA/CGPA pages, student onboarding, and additional academic interfaces, including MCA-related pages.

## ✨ Project Areas
- SGPA and CGPA calculators
- Student onboarding and selection pages
- Academic program-specific pages
- Frontend interface and JavaScript functionality
- Firebase/server components present in the repository

## 🧰 Tech Stack
- HTML
- CSS
- JavaScript
- Node.js / Firebase components, where configured

## 🚀 Getting Started
1. Clone the repository.
2. Review the project files and `package.json`, if present.
3. Configure Firebase and server settings locally.
4. Run the app using the available scripts or serve the HTML pages locally.

## 🔐 Security
Keep environment files, credentials, and private keys out of version control. Check repository history if any secret has previously been committed.
